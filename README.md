## Sobre o projeto

PyCalc e uma calculadora desenvolvida em Python puro,
executada diretamente pelo terminal.

O projeto foi criado para praticar logica de programacao,
funcoes, modularizacao e tratamento de excecoes.

## Funcionalidades

- Adicao
- Subtracao
- Multiplicacao
- Divisao
- Potenciacao
- Raiz quadrada
- Porcentagem
- Historico de operacoes
- Limpeza do historico
- Tratamento de erros

## Como executar

Clone o repositorio:

```bash
git clone https://github.com/PedroGFCarneiro/PyCalc.git
```

Entre na pasta:

```bash
cd PyCalc
```

Execute:

```bash
python main.py
```

No Windows, tambem pode utilizar:

```bash
py main.py
```

Nao existem dependencias externas.
